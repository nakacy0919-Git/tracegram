# Tracegram Classroom Arena（開発ブランチ）

## 遊び方

1. ホームの **みんなで文法バトル** → **ルームを作成**。表示名はニックネームで構いません。
2. ホストの6桁コードを伝えるか、**参加用QRを表示**し、生徒のiPadで読み込みます。
3. 参加者は各端末でTracegramを開き、表示名を設定して参加します。
4. ホストが既存の文法教材・難易度・5/10/20/50問などの問題数を選択します。
5. ロビーでゲーム形式を選び、2人以上で開始します。**チーム対抗は4人専用**です。
6. 全員に同じ問題が同じ順番で表示されます。対戦中は進捗・得点を共有し、👏 🔥 💡 のエールを送れます。

## モード

| モード | 教育的ねらい | 評価方法 |
| --- | --- | --- |
| スピードバトル | 一人ひとりが同じ文構造に挑戦 | 個人スコアのライブ順位 |
| 協力チャレンジ | 互いに励ましながら全問をクリア | 全員の正解数の合計と終了人数 |
| チーム対抗 2 vs 2 | ペアで得点を積み上げる | A/Bチームの総得点（席順で自動振り分け） |

**得点上の補足:** 既存のTracegram採点ロジック（初回正答、コンボ）をそのまま使用します。全員が同じ問題・順番で競い、対戦では一筆フローに統一します。出題は最大50問です。先生がローカル端末に保存したオリジナル問題・まちがいノートはほかの端末から参照できないため、対戦では使用できません。

## 通信・プライバシー

- **同じWi-Fiでの自動発見や完全オフラインLAN対戦ではありません。** PeerJSの公開シグナリングサービスにインターネット経由でつなぎ、WebRTC接続を確立します。学校ネットワークのWebRTC/STUN制限により失敗する場合があります。
- 専用のSupabase/Firebase/データベースは追加していません。アカウント不要。サーバー側に成績を保存しません。表示名、スコア、進捗、エールは参加端末間で共有されます。
- PeerJSは外部のシグナリングサービスを利用するため、接続用の識別子などがサービス側に見える可能性があります。実名や個人情報を入力しない運用を推奨します。
- 6桁コードは教室用の短期的な合言葉であり、認証システムや不正対策ではありません。競技会など厳密な本人確認が必要な環境には向きません。
- ルームはホストのブラウザーが閉じられると終了します。大人数の全クラス同時接続ではなく、**2〜4人のグループごとの学習**を想定しています。

## 検証方法

```bash
npm ci
npm run check:battle
npm run build
```

実際のiPadで以下を確認してください：

- ホスト1台＋ゲスト1〜3台を同時接続できる
- QRから入り、6桁コードが入力される
- 2台で同じ問題・同じ順番・同じ問題数になる
- 3形式の集計が正しく更新される（チーム戦は4台）
- 接続切断、満員、誤PIN、ホスト終了、再戦
- Wi-FiがWebRTCをブロックした場合にエラーメッセージが表示される
- iPad横画面で問題と対戦情報が重ならない
